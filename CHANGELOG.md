# Changelog

## 0.2.0

- Init installs Codex, Claude, Gemini and Antigravity together by default; select any subset with CSV or repeated --with flags.
- Install seven discoverable, namespaced skills in each selected platform's native skills directory, resolving shared/project workflows through one portable router.
- Add missing platform files and skills without replacing existing user content; init --refresh updates only managed instruction blocks.
- Antigravity rules use .agents/rules with always_on frontmatter; native skills/rules participate in protected governance fingerprints.
- Rewrite the Vietnamese onboarding guide around one-command installation, resulting folders, each skill's purpose, prompts and task lifecycle.
- Verify default/subset initialization, additive installs, native file preservation, refresh, execution locks and native governance through package and registry smoke checks.
